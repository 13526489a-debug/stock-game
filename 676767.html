線上多人連線設定 (Firebase)

由於 GitHub Pages 為純靜態網頁託管，若要與遠端朋友跨裝置即時連線，請貼上您免費申請的 Firebase Config JSON（支援 Realtime Database 或 Firestore）。若未設定，系統也會在同瀏覽器分頁間模擬同步，或可直接使用「單人 AI 模式」。

部署至 GitHub Pages 指南

本遊戲已將所有 HTML、CSS 與多人連線邏輯打包為單一檔案，只需 3 步驟即可免費上線：

  1. 點擊下方按鈕下載 index.html（若您已填入 Firebase Config，下載的檔案會自動內嵌您的連線金鑰，好友打開網址即可直接連線！）。
  2. 前往 GitHub 建立一個新的公開儲存庫 (Repository)，例如 stock-trading-game，並上傳 index.html。
  3. 進入儲存庫的 Settings → Pages，將 Branch 設為 main 並儲存，約 1 分鐘後即可獲得專屬遊戲網址！
